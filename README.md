# Fisheye Dewarp Movie Maker

円周魚眼カメラで撮影した動画を、ブラウザだけでデワープ（歪みのない平面の映像へ変換）して再生し、動画として保存できる Web アプリです。

https://hugehoge.github.io/fisheye-dewarp-movie-maker/

動画の処理はすべてブラウザの中で行います。動画が外部へ送信されることはありません。

## 対応ブラウザ

パソコン版の Google Chrome と Microsoft Edge です。

## 使い方

1. 「動画ファイルを選択」から動画を開くか、画面に動画ファイルをドロップします。
2. カメラの設置方向を選びます。
   - **天井付け（下向き）**: カメラが真下を向いている場合に選びます。パンで周囲を一周見回せます。
   - **壁付け（横向き）**: カメラが水平方向を向いている場合に選びます。
3. 映像をドラッグしてパン・チルトを、ホイールで画角を調整します。画面右のスライダーでも調整できます。
4. 解像度を選んで「現在の視野に変換して保存」を押し、保存先を指定します。

保存では、元の動画ファイルの最初から最後までを、ボタンを押した時点の視野でデワープした動画に変換します。プレビューの録画ではないので、再生位置や再生・停止の状態には影響されません。

## 保存される動画

| 項目           | 内容                                  |
| -------------- | ------------------------------------- |
| 形式           | MP4（映像は H.264）                   |
| 音声           | 元の動画の音声をそのままコピー        |
| フレームレート | 元の動画と同じ                        |
| 縦横比         | 16:9                                  |
| ファイル名     | `<元のファイル名>_dewarp.mp4`（候補） |

解像度は次の 3 つから選べます。

| 解像度    | ビットレート | サイズの目安       |
| --------- | ------------ | ------------------ |
| 1920×1080 | 8 Mbps       | 1 分あたり約 60 MB |
| 1280×720  | 5 Mbps       | 1 分あたり約 38 MB |
| 854×480   | 2.5 Mbps     | 1 分あたり約 19 MB |

ビットレートとサイズは、30 fps の動画での目安です。フレームレートが 30 fps より低い動画ではそれに比例して小さく、高い動画では大きくなります。ブラウザや機種によって異なる場合があります。

## 対応する映像と制限

- 想定している入力は、H.264 の MP4（2160×2160 まで）です。
- 等距離射影・画角 180° の円周魚眼を前提にしています。映像の円（イメージサークル）がフレームの中央にあり、短辺いっぱいに写っている必要があります。
- カメラが光軸のまわりに回転して設置されている場合の補正（ロール）には対応していません。
- レンズに写っていない方向は、黒で表示されます。
- 保存の途中でタブを閉じたり再読み込みしたりすると、保存は中断されます。

## 開発

Node.js と pnpm のバージョンは、[mise](https://mise.jdx.dev/) で固定しています。

```sh
mise install
pnpm install
pnpm dev
```

mise を使わない場合は、`mise.toml` に書かれたバージョンの Node.js と pnpm を用意してください。

| コマンド       | 内容                                |
| -------------- | ----------------------------------- |
| `pnpm dev`     | 開発サーバーを起動する              |
| `pnpm build`   | 型チェックとビルドを行う（`dist/`） |
| `pnpm preview` | ビルド結果をローカルで配信する      |
| `pnpm lint`    | Oxlint で検査する                   |
| `pnpm fmt`     | Oxfmt で整形する                    |
| `pnpm test`    | Vitest で単体テストを実行する       |

### しくみ

- **デワープ**: WebGL2 のシェーダーで、魚眼の映像を平面の映像へ変換します（`src/dewarp/`）。プレビューと保存で同じ描画を使います。
- **保存**: 専用のワーカーが、元のファイルの全フレームをデコードし、デワープして、H.264 に再エンコードします（`src/export/`）。コーデックはブラウザの WebCodecs、MP4 の読み書きは [Mediabunny](https://mediabunny.dev/) を使います。

### デプロイ

`main` ブランチへ push すると、GitHub Actions が GitHub Pages へデプロイします（`.github/workflows/deploy.yml`）。リポジトリの Settings → Pages で、Source を「GitHub Actions」にしておく必要があります。
